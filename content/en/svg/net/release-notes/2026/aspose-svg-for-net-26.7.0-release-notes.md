As per the regular monthly update process of all APIs being offered by Aspose, we are honored to announce the July release of Aspose.SVG for .NET.

### Release Notes

Aspose.SVG for .NET 26.7.0 is published as part of the July monthly release.

**Package references**<br>
Aspose.SVG for .NET 26.7.0 [NuGet](https://www.nuget.org/packages/Aspose.Svg)<br>
Aspose.SVG for Python via .NET  26.7.0 [PyPI](https://pypi.org/project/aspose-svg-net/)

## **Improvements and Changes**

- Maintenance build for the July 26.7.0 release of Aspose.SVG for .NET.
- Improved the performance of SVG path geometry calculations: the arc-length evaluation for cubic Bézier curve segments has been optimized, making `SVGPathElement.getTotalLength()` and `getPointAtLength()` significantly faster, especially on paths with many curve segments.
