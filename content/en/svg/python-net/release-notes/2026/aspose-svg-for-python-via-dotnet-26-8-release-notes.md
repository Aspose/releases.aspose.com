As per the regular monthly update process of all APIs being offered by Aspose, we are honored to announce the August release of Aspose.SVG for Python via .NET.

### Release Notes

Aspose.SVG for Python via .NET 26.8.0 is published as part of the August monthly release.

**Package references**<br>
Aspose.SVG for Python via .NET 26.8.0 [NuGet](https://www.nuget.org/packages/Aspose.Svg)

## **Improvements and Changes**

- `SVGTextContentElement.GetComputedTextLength()` now returns the actual text advance distance for `<text>` content.
- Improved parameter binding between the scripting engine and the DOM, so callbacks passed to platform methods are invoked reliably.
