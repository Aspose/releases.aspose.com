## **Public API and Backwards Incompatible Changes**

The following is a list of any changes made to the public API such as added, renamed, removed or deprecated members as well as any non-backward compatible change made to Aspose.Cells for Go via C++. If you have concerns about any change listed, please raise it on the Aspose.Cells support forum.

### **Adds two methods in BorderCollection class.**

Indicates if left, right, top, and bottom borders should be applied only to outside borders of a cell range. Default value is true.

{{% alert color="primary" %}}

func (instance *BorderCollection) IsOutline() (bool, error)

func (instance *BorderCollection) SetIsOutline(value bool) error

{{% /alert %}}

### **Adds one method in Cell class.**

Gets a Picture which wrapped the embedded image in the cell.

{{% alert color="primary" %}}

func (instance *Cell) GetPicture() (*Picture, error)

{{% /alert %}}

### **Adds and obsoletes some methods in ShapePath class.**

Add:

Gets ShapeSegmentPathCollection list

{{% alert color="primary" %}}

func (instance *ShapePath) GetPathSegments() (*ShapeSegmentPathCollection, error)

{{% /alert %}}

Obsoletes:

Please use ShapePath.GetPathSegments() method instead.

{{% alert color="primary" %}}

func (instance *ShapePath) GetPathSegementList() (*ShapeSegmentPathCollection, error)

{{% /alert %}}

### **Adds and obsoletes some methods in HtmlLoadOptions class.**

Add:

Specifies how HTML &lt;p&gt; elements are rendered when loading HTML. The default value is HtmlParagraphLayoutMode.Normal.

{{% alert color="primary" %}}

func (instance *HtmlLoadOptions) GetParagraphLayoutMode() (HtmlParagraphLayoutMode, error)

func (instance *HtmlLoadOptions) SetParagraphLayoutMode(value HtmlParagraphLayoutMode) error

{{% /alert %}}

Obsoletes:

Please use HtmlLoadOptions.GetParagraphLayoutMode()/HtmlLoadOptions.SetParagraphLayoutMode(HtmlParagraphLayoutMode) methods instead.

{{% alert color="primary" %}}

func (instance *HtmlLoadOptions) GetParagrahLayoutMode() (HtmlParagraphLayoutMode, error)

func (instance *HtmlLoadOptions) SetParagrahLayoutMode(value HtmlParagraphLayoutMode) error

{{% /alert %}}

### **Adds and obsoletes some methods in PaneCollection class.**

Add:

Gets and sets the active pane.

{{% alert color="primary" %}}

func (instance *PaneCollection) GetActivePaneType() (RectangleAlignmentType, error)

func (instance *PaneCollection) SetActivePaneType(value RectangleAlignmentType) error

{{% /alert %}}

Obsoletes:

Please use PaneCollection.GetActivePaneType()/PaneCollection.SetActivePaneType(RectangleAlignmentType) methods instead.

{{% alert color="primary" %}}

func (instance *PaneCollection) GetAcitvePaneType() (RectangleAlignmentType, error)

func (instance *PaneCollection) SetAcitvePaneType(value RectangleAlignmentType) error

{{% /alert %}}

### **Obsoletes class CustomPiovtFieldGroupItem.**

Please use DiscreteGroupItem class instead.

### **Adds new class DiscreteGroupItem.**

Represents an item of custom grouped field.

### **Adds and obsoletes some methods in PivotDiscreteGroupSettings class.**

Add:

Gets the discrete items.

{{% alert color="primary" %}}

func (instance *PivotDiscreteGroupSettings) GetDiscreteItems() ([]DiscreteGroupItem, error)

{{% /alert %}}

Obsoletes:

Please use PivotField.GroupBy([]DiscreteGroupItem, bool) method instead.

{{% alert color="primary" %}}

func (instance *PivotDiscreteGroupSettings) GetItems() ([]CustomPiovtFieldGroupItem, error)

{{% /alert %}}
