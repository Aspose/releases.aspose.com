This page contains release notes for Aspose.HTML for Java 26.12

{{% /alert %}}

We are honored to announce the December release of Aspose.HTML for Java.

This release brings a series of refinements to the processing of visual content in HTML and SVG documents.

Updated SVG mask processing to account for coordinate transformations and the bounding boxes of transformed graphical elements. Refined SVG text layout calculations and the handling of element boundaries during rendering.

Expanded SVG optimization with additional steps for removing unnecessary stroke and fill properties, cleaning lists of values, and removing indentation and line breaks from SVG markup.

Refined font processing with updates to character-to-glyph mapping, glyph lookup, and font metrics handling. Updated font resource recognition to include additional MIME type variations for existing web font formats.
