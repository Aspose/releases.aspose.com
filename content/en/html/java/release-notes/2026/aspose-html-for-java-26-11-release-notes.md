This page contains release notes for Aspose.HTML for Java 26.11

{{% /alert %}}

As per the regular monthly being offered by Aspose, 
we are honored to announce the November release of Aspose.HTML for Java.

In this release, we have introduced improvements to SVG path data processing, thread-local state management, file system operations, and data handling.

Improved SVG path data conversion by refining numeric parameter formatting, correcting the construction of elliptical arc segments, and ensuring that calculated path data is properly returned. These changes provide more consistent handling of SVG path commands and their parameters.

Enhanced thread-local state management by updating thread-specific value initialization and refining the handling of thread-local resources. These changes improve the consistency of thread-related operations within the Java compatibility layer.

Extended file system utilities with directory path validation and working directory configuration support. The update also improves JSON text reading and refines indexed collection filtering, providing more consistent behavior across supporting components.
