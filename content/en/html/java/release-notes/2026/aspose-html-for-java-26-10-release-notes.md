This page contains release notes for Aspose.HTML for Java 26.10

{{% /alert %}}

We are honored to announce the October release of Aspose.HTML for Java.

In this release, we have introduced several improvements to character handling and font-related utilities used by the HTML processing engine.

Improved character processing by implementing Unicode whitespace and punctuation detection, ASCII control-character recognition, and checks for special characters used in email usernames and URIs. Added conversion of character codes to UTF-16 and updated identifier handling to recognize names beginning with two hyphens. These changes provide more consistent character classification and parsing.

Extended font-related utilities with Unicode-range lookup for characters and conversion of font-stretch values to percentage-based widths. Added support for resolving the local Windows user fonts directory, extending the font discovery capabilities on Windows.
