This page contains release notes for Aspose.HTML for Java 26.7

{{% /alert %}}

We are pleased to announce the July release of Aspose.HTML for Java.

This release adds support for rendering image attachments embedded in MHTML documents during MHTML-to-PDF conversion. Image attachments that are not referenced by the main HTML document are now rendered as separate pages in the output PDF.

Supported image formats include JPEG, PNG, GIF, BMP, WebP, and TIFF.
