This page contains release notes information for Aspose.PUB for .NET 26.10.

Aspose.PUB for .NET is a сonvenient library that provides the feature to convert Microsoft Publisher documents. The library is in compliance with the .NET 7.0 and also supports .NET 6.0, .NET 5.0, .NET Standard 2.0, and .NET Standard 2.1. .NET 8.0 target framework support has been added. You can use it for application development in any IDE that targets the .NET platform.  

## Improvements and Changes

Optimized PDF processing functionality.
