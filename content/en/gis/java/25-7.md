Aspose.GIS for Java is a Java class library to read, create, edit, convert and render geospatial data. It enables developers to work with vector and raster formats, perform geometry operations, transform spatial reference systems and render maps without requiring third-party GIS software.

## Geospatial Data Processing

- Read, create, edit and convert vector layers and datasets.
- Render maps to PNG, JPEG, BMP and SVG.
- Create and analyze geometries, including points, lines and polygons.
- Work with non-linear curves and linearize them.
- Transform spatial reference systems and reproject data.
- Customize map styling and geometry symbolizers.

## Read & Write GIS Formats

**ESRI Shapefile:** SHP, SHX, DBF, QIX, CPG\
**GeoJSON:** JSON, GeoJSON\
**ESRI File Geodatabase:** GDB\
**Google Earth:** KML\
**GPS Exchange Format:** GPX\
**TopoJSON:** JSON, TopoJSON\
**MapInfo Tab Format:** TAB, DAT, DBF, MAP, ID

## Read GIS Formats

**Geography Markup Language:** GML\
**MapInfo Interchange Format:** MIF\
**OpenStreetMap:** OSM\
**Raster:** GeoTIFF, ESRI ASCII\
**Web Tiles:** XYZ Tiles\
**Databases:** PostGIS, Microsoft SQL Server

## Map Rendering Formats

**Images:** SVG, PNG, JPEG, BMP

## Supported Environments

- **Microsoft Windows:** Windows Desktop & Server (x86, x64)
- **macOS:** Mac OS X
- **Linux:** Ubuntu, OpenSUSE, CentOS, and others
- **Java Versions:** `Java SE 16` or above

## Get Started

Aspose.GIS Java APIs are hosted at the [Aspose.GIS Repository](https://releases.aspose.com/java/repo/com/aspose/aspose-gis/). You can easily use Aspose.GIS for Java API directly in your Maven projects with simple configurations.

## Read a GeoJSON Layer

```java
import com.aspose.gis.Drivers;
import com.aspose.gis.Feature;
import com.aspose.gis.VectorLayer;

public class ReadGeoJson {
    public static void main(String[] args) {
        VectorLayer layer = VectorLayer.open("data.geojson", Drivers.getGeoJson());
        try {
            for (Feature feature : layer) {
                System.out.println(feature.getGeometry().asText());
            }
        } finally {
            layer.dispose();
        }
    }
}
```

## Create a GeoJSON File and Convert It to Shapefile

```java
VectorLayer layer = VectorLayer.create("cities.geojson", Drivers.getGeoJson());
try {
    layer.getAttributes().add(new FeatureAttribute("name", AttributeDataType.String));
    Feature feature = layer.constructFeature();
    feature.setGeometry(new Point(74.3587, 31.5204));
    feature.setValue("name", "Lahore");
    layer.add(feature);
} finally {
    layer.dispose();
}
VectorLayer.convert("cities.geojson", Drivers.getGeoJson(), "cities.shp", Drivers.getShapefile());
```
