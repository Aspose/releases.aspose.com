## Aspose.TeX 26.8 for .NET has been released!

- Improved handling of closed and non-seekable input streams to prevent typesetting failures during file-size and metered-size processing.
- Improved font conversion resilience when only part of the Aspose.Font assembly type set can be loaded.
- Improved Aspose.TeX.Drawing deployment by embedding Aspose.Drawing into .NET Core builds and correcting Aspose.Page dependency resolution for .NET 7.

| - | Prevent font conversion failures when assembly types cannot be fully loaded | Bug |
