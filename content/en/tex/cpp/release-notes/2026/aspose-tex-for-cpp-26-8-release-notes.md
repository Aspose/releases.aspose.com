## Improvements and Changes

Aspose.TeX for C++ 26.8 is based on latest [Aspose.TeX for .NET 26.8](https://releases.aspose.com/tex/net/release-notes/2026/aspose-tex-for-net-26-8-release-notes/) and ready for use with Aspose C++ products ver 26.8.

- Improved handling of closed and non-seekable input streams to prevent typesetting failures during file-size and metered-size processing.
- Improved font conversion resilience when only part of the Aspose.Font assembly type set can be loaded.


You can consult Aspose.TeX for C++ [API reference](https://reference.aspose.com/tex/cpp/) for documentation.
