## Improvements and Changes

The functionality for handling **cmap format 2** tables has been improved. Fixed *OutOfMemoryException* when calling **TtfCMapFormat4Table.GetAllCodes**.

# List of Issues Covering all Changes in this Release
| Key | Summary | Category |
|---|---|---|
| FONTNET-927 | OutOfMemoryException when calling TtfCMapFormat4Table.GetAllCodes | Bug |
| FONTNET-919 | Improve handling of **cmap format 2** tables | Feature |
